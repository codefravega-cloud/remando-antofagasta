Antes de salir

Preguntas
frecuentes.

¿Necesito saber remar? +

No. La clase inicial está pensada para aprender desde cero y el instructor adapta el recorrido a las condiciones.

¿Qué llevo? +

Traje de baño, bloqueador, agua y una toalla. Confirma por WhatsApp si necesitas recomendaciones para ese día.

¿Qué pasa si cambian las condiciones del mar? +

La seguridad manda. Si las condiciones no son adecuadas, se coordina una nueva fecha u horario disponible.

¿Puedo reservar para un grupo? +

Sí. Elige una hora con más de un cupo o escríbenos para coordinar una salida especial.
